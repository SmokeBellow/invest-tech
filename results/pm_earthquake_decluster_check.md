# Earthquake model — проверка независимости наблюдений (declustering)

Наивный t-test по отдельным бакетам ('exactly N earthquakes') завышает значимость — несколько бакетов часто описывают ОДНУ неделю/магнитуду, их исходы механически коррелированы (см. докстринг). Группируем по (magnitude, период) и считаем P&L НА СОБЫТИЕ, не на бакет.
